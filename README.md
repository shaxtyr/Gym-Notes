Описание:
приложение для отслеживания прогресса тренировок

Стек:
UI: Compose + MVI
DB: Room
DI: Koin

Экраны:
экран отображения дат проведенных тренировок
экран подробного описания тренировок за конкретную дату
экран списка упражнений для разных категорий
экран достижений по каждому из упражнений

Возможности:
добавление/редактирование/удаление собственных упражнений в категорию (хранятся в базе данных)
создание/удаление заметки (хранятся в базе данных)
возможность выбора светлой/темной темы (хранится в DataStore)
секундомер для отдыха между подходами
